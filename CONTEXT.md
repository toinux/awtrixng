# AWTRIX Applications

This context covers independently installable applications displayed by AWTRIX NG and the source projects maintained for them.

## Language

**Application**:
An independently named display experience that can take a turn in the AWTRIX rotation and retains its own settings and state.
_Avoid_: Script, when referring to the on-device experience

**Script**:
The Berry source program that implements an application.
_Avoid_: App, when referring specifically to source code

**Project**:
The maintained source and supporting materials for one application, kept together as a unit.
_Avoid_: Repository, app, when referring to the app's source package

**Release**:
A published, versioned installable artifact for one application; applications can be released independently.
_Avoid_: Repository release, combined release
